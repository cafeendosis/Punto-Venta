# Punto-Venta

API para gestionar productos, lotes de inventario y ventas de una tienda de abarrotes.

## Instalación

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Ejecución

```bash
uvicorn main:app --reload
```

La documentación interactiva queda disponible en `/docs`.
